# Teclado en ventas

Los atajos funcionan dentro de la ventana de ventas, incluso mientras se escribe en un campo.

| Tecla | Acción |
| --- | --- |
| F1 | Mostrar ayuda de teclado |
| F2 | Nueva compra, con confirmación antes de vaciar el carrito |
| F3 | Ir a Paga con y seleccionar el importe para reemplazarlo |
| F4 | Abrir consulta de precio |
| F5 | Volver al código de barras |
| F6 | Ir al selector de productos sin código |
| F7 | Quitar el producto seleccionado, con confirmación |
| F8 | Calcular vuelto |
| F9 | Imprimir ticket |
| Enter en código de barras | Agregar producto |
| Enter en Paga con | Calcular vuelto |
| Enter en precio sin código | Agregar el producto sin código |
| Tab / Shift+Tab | Avanzar / retroceder entre controles |
| Esc en consulta de precio | Cerrar la consulta |

En las confirmaciones de nueva compra y quitar producto, Enter acepta y Esc cancela.
Si se mueve el foco a Cancelar con Tab, Enter cancela. Cerrar el diálogo con la X también cancela.

En notebooks puede ser necesario usar Fn junto con las teclas F, según la configuración del teclado.
